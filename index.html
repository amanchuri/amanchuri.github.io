FAQ

Answers to common questions about using UrbanBloom for sustainable building planning.

Does the planner use real building data?

The tool relies on climate, orientation and material characteristics to match systems and plants from its knowledge base.

Can I compare different budgets?

Yes. Budget input affects cost guidance and preferred installation complexity, so the output stays aligned with project expectations.

Are irrigation needs included?

Yes. Rainfall, climate and plant water profiles drive irrigation recommendations and maintenance level estimates.

Is there an exportable summary?

UrbanBloom generates a clean report summary you can download as a text file for stakeholder review.
